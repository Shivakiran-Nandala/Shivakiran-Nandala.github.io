## 📤 How to Deploy to GitHub

### Step 1: Push to GitHub

1. Click **"Save to GitHub"** button in Emergent
2. Select your repository
3. Push the files

### Step 2: Enable GitHub Pages

1. Go to your GitHub repository
2. Click **Settings** (gear icon)
3. Scroll down to **Pages** section (left sidebar)
4. Under **Source**:
   - Branch: Select `main` (or `master`)
   - Folder: Select `/ (root)`
5. Click **Save**

### Step 3: Wait & Visit

- GitHub will build your site (takes 1-2 minutes)
- Your portfolio will be live at:
  ```
  https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/
  ```

## 🆘 Troubleshooting

### Portfolio not showing up?
- Wait 2-5 minutes after enabling Pages
- Check Settings → Pages shows green checkmark
- Clear browser cache

### 404 Error?
- Verify your URL is correct
- Check Settings → Pages → Source is set to `main` branch and `/ (root)` folder

### Styles not loading?
- Make sure all files (`index.html`, `style.css`, `script.js`) are in the root directory
- Check file names are exactly correct (case-sensitive)
